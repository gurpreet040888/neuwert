# Neuwert Website

Static responsive website for Neuwert — Data • AI • Engineering.

## Pages
- index.html — Home
- services.html — Services
- careers.html — Careers / open roles
- contact.html — Contact and enquiry form
- styles.css — Shared styling
- assets/neuwert-logo.png — Brand logo

## Deployment
Upload the entire folder to any static host such as Netlify, Vercel, GitHub Pages, Cloudflare Pages, or an ordinary web server.

The contact form uses a mailto action and does not require a backend. For production, it can later be connected to a CRM or form service.

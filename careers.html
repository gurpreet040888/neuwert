Data Engineer

Full-time · Remote / Hybrid · Data Engineering
OPEN

About the role

Design and develop scalable data pipelines, ETL workflows and cloud data solutions. You’ll work with senior engineers and client teams to build reliable data platforms across AWS and modern data warehouses.

What you’ll do

  • Develop batch and near-real-time ETL / ELT pipelines using Python, PySpark and SQL.
  • Build and maintain data workflows using tools such as Airflow, Informatica or SSIS.
  • Work with Snowflake, SQL Server, Oracle and other enterprise databases.
  • Build cloud data solutions using AWS services such as Kinesis, Glue, Lambda, EMR and S3.
  • Develop data models, transformations, validation and performance improvements.
  • Collaborate with architects, analysts, product teams and engineering leadership.

What we’re looking for

  • Strong SQL and practical data-engineering experience.
  • Hands-on experience with ETL / ELT and data pipelines.
  • Experience with Python or PySpark.
  • Exposure to Snowflake and/or SQL Server / Oracle.
  • Working knowledge of AWS data services is a strong advantage.

Engineering Manager — Data

Full-time · Remote / Hybrid · Engineering Leadership
OPEN

About the role

Lead a growing data-engineering team delivering cloud data platforms, ETL modernization, analytics and AI-ready data solutions. This role combines people leadership, architecture, delivery ownership and technical direction.

What you’ll do

  • Lead, mentor and grow data engineers across multiple projects and client engagements.
  • Own technical planning, estimation, architecture reviews and delivery execution.
  • Guide solutions across ETL, Snowflake, SQL Server, Oracle and AWS.
  • Establish engineering standards for quality, testing, observability, security and documentation.
  • Partner with business and technology stakeholders to define roadmaps and priorities.
  • Support hiring, capability development and technical career growth.

What we’re looking for

  • Strong background in data engineering and enterprise data platforms.
  • Experience leading or managing engineering teams.
  • Strong SQL and ETL architecture experience.
  • Hands-on knowledge of cloud data platforms, especially AWS.
  • Experience with Snowflake, SQL Server, Oracle or comparable technologies.
  • Excellent communication, planning and stakeholder-management skills.
